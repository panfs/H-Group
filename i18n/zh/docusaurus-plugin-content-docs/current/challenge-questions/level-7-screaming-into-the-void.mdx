- Alice 应该打出她的绿色 3。

- Alice 执行[_尖叫弃牌_](../level-7.mdx#the-scream-discard-chop-move-sdcm)是不合法的，因为那只应该在万不得已的情况下使用，而由于 Bob 预计在这个回合打出黄色 3，所以这不会是万不得已的情况。
